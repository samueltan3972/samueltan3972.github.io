Privacy policy: Sam Personal MCP

Sam Personal MCP is a private tool used only by its owner, Samuel Tan, with the owner's own Google accounts.

What data it accesses

With the owner's sign-in, it accesses the owner's own Google data that the owner has allowed: Calendar, Tasks, Gmail, Drive, Docs, Sheets, Slides, Contacts, Forms, Apps Script and YouTube (read-only).

How the data is used

The data is used only to answer the owner's own requests through the owner's AI assistants. Sign-in tokens are stored on the owner's home server and are not reachable from the internet.

Sharing

The data is not sold, not shared with third parties and not used for advertising. This tool does not use it to train AI models. Content is sent to an AI assistant service only when the owner asks that assistant a question, and that service handles it under its own terms.

Google API data

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

The owner can remove this tool's access at any time from Google Account → Third-party connections, which also makes the stored sign-in tokens stop working.
