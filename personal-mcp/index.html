Sam Personal MCP

Sam Personal MCP is a private, self-hosted tool used only by its owner, Samuel Tan. It runs on the owner's own home server and lets the owner's AI assistants read and manage the owner's own Google Calendar, Tasks, Gmail, Drive, Docs, Sheets, Slides, Contacts, Forms, Apps Script and YouTube account.

It is not offered to the public, and no one else can sign in to it.
